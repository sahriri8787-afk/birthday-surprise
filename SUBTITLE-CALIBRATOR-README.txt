Birthday Surprise - Subtitle Calibrator

1) Run the project with python http.server.
2) Open: http://127.0.0.1:8081/subtitle-calibrator.html
3) Press play. At the exact moment each lyric line starts, tap the big register button.
4) Fine tune any line with +/- 0.05s and +/- 0.10s.
5) Timings auto-save in localStorage and index.html uses them automatically.
6) Use Copy timings or Download JSON to send the final timings back if needed.
